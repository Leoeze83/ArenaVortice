# 📜 Reglas del Proyecto: Arena Vórtice

Estas reglas son mandatorias y el agente Antigravity debe consultarlas y respetarlas en cada inicio de sesión:

1. **Idioma principal**: Responder SIEMPRE en español. Si hay algo que el usuario deba completar en inglés (como nombres de propiedades de Roblox o palabras clave del código), aclararlo explícitamente para que se comprenda que el procedimiento lo requiere así.
2. **Contexto y Diseño (GDD)**: La documentación inicial proporcionada para crear el proyecto está en la carpeta `Doc_inicial`. Cada vez que se necesite recordar cuál es el enfoque del proyecto (mapa, personajes, reglas), recurrir ahí y repasarlo.
3. **Estado y Seguimiento**: Al iniciar una nueva sesión, o si hay dudas sobre el progreso de las tareas, investigar obligatoriamente la documentación que está en la carpeta `Documentacion del Proyecto` (especialmente `Estado_Proyecto.md` y `Changelog.md`). Es de suma importancia mantener actualizada esta documentación durante el trabajo para entender en qué parte estamos y el estado del proyecto.
4. **Control de Versiones (GitHub)**: Al concluir cada fase y recibir la aprobación del usuario, subir los cambios al repositorio en GitHub (hacer commits y push). Recordar siempre mantener la privacidad de los datos y la seguridad del proyecto.
